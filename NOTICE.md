This repository is an original phone-first implementation inspired by the open,
hardware-adapter philosophy of the Omi project. It does not copy the Omi mobile
application or firmware and does not require Omi hardware.

- Omi: MIT, https://github.com/BasedHardware/omi

- React Native Audio API: MIT, https://github.com/software-mansion/react-native-audio-api

Model weights can carry their own licences. Pillar 9 must approve every model,
dataset and licence before production deployment.
